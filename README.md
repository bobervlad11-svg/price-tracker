# Price Tracker

Скрипт на Python, который показывает, как изменились цены криптовалют с прошлого запуска.

## Что умеет

- Получает текущие цены Bitcoin, Ethereum и Solana через CoinGecko API
- Сохраняет цены в файл `last_price.json` и при следующем запуске сравнивает с ними
- Показывает изменение в процентах для каждой монеты
- Выводит итог: сколько монет выросло и сколько упало
- Не падает, если API не вернул цену монеты: пропускает её и идёт дальше

## Как запустить

1. Установить Python 3 и библиотеку requests:
   `pip install requests`
2. Запустить скрипт:
   `python price_tracker.py`

При первом запуске сравнивать пока не с чем: скрипт только сохраняет текущие цены. Изменения появятся при втором запуске.

## Технологии

- Python, JSON
- [requests](https://pypi.org/project/requests/)
- [CoinGecko API](https://www.coingecko.com/en/api)
